# Studio Denise Vieira — landing page

Landing page (HTML, CSS e JS puros) do perfil [@studio_denisevieira](https://www.instagram.com/studio_denisevieira/):
extensão de cílios e alongamento de unhas em Planaltina-DF.

## Ver localmente
Abrir `index.html` no navegador, ou servir a pasta:

```bash
python3 -m http.server 5180
```

## Pendente (pedir à cliente)
- **WhatsApp**: (61) 99979-5209 — já configurado em `CONFIG.whatsapp` no `script.js`.
- **Endereço** (opcional): `CONFIG.endereco` no `script.js`.
- **Valores**: o site não mostra preços; os botões pedem "consultar valor" pelo WhatsApp.
- **Depoimentos**: o destaque "FeedBacks" do Instagram pode virar uma secção de depoimentos (prints ou texto real das clientes).

## Fotos
- `img/cilios`, `img/unhas` — galeria (lista `GALERIA` no `script.js`; para adicionar, coloque `17.jpg` etc. e aumente a lista).
- `img/denise` — fotos da Denise (hero e "Quem sou eu").
- `img/studio` — o espaço.
Fotos tiradas do Instagram da cliente em 17/11/2026, redimensionadas para no máximo 1400 px.
